## Varta (वार्ता)

A modern, uplifting and solution-focused news platform celebrating human progress, scientific breakthroughs, and community resilience.

### Repository Architecture
- `VartaCore/`: Minimal modular monolith Go backend (`net/http`, MySQL, Redis, RSS Ingestion Pipeline)
- `VartaUI/`: Responsive React + Vite frontend with curated topic categories and joy index metrics
